# 리서치 코퍼스 안내 (사용자용 · 한국어)

> 이 `research/` 폴더는 **"현업 시니어 엔지니어는 어떻게 하는가"**에 대한 근거 기반 레퍼런스예요.
> gingoa를 빌드하는 내내 계속 참고하는 기준점입니다. (이 파일만 한국어 — 나머지는 전부 LLM이 읽을 영어.)

## 한 장 요약
- **이게 뭐냐:** 소프트웨어를 production-grade로 만드는 데 필요한 모든 엔지니어링 영역(aspect)의 업계 표준을,
  유명 논문·표준(SWEBOK·ISO 등)과 실제 repo 통계(census)로 정리한 지식 베이스.
- **왜 분리돼 있냐:** 이건 *일반 표준*이고, gingoa가 *자기 프로젝트에 실제로 내린 결정*(`docs/internal/`의
  contract·계획·ADR)과는 다른 층이에요. 각 aspect 문서가 `gingoa_applied`로 그 적용을 연결합니다.
- **축:** 지식은 **aspect(영역)별**로 한 번만 저장하고, gingoa가 사용자를 **라이프사이클(①기획→②포석→③구현→
  ④릴리스·운영)**로 끌고 가며 단계마다 해당 aspect를 활성화해요. (`lifecycle.md`가 그 단계↔aspect 지도.)

## gingoa가 모델을 이끄는 법 (운영모델 · ADR-0013/0014)
**gingoa = AI 모델 옆에 앉은 시니어 멘토.** 위 규칙책(코퍼스)을 들고 아이디어를 ①기획→②포석→③구현→④릴리스로
끌고 가며, 단계마다 **5가지 방식 중 하나**로 모델을 이끕니다. (모델 = 뭐든 빠르게 짜는 유능한 주니어 — 안 시키면
보안·롤백·테스트를 건너뜀. gingoa가 그 공백을 메움.) 전달 수단은 고정 = **skills(과정 진행)·hooks(자동 가드)·
mcp(규칙책 조회 + 대시보드).**

"템플릿이냐 LLM이냐?" → **둘 다, 종류별로 나눠서:**

| 방식 | 언제 | 예시(운동 기록 웹앱) |
|---|---|---|
| ① 템플릿 (결정론적 바닥) | 정답이 정해진 boilerplate | package.json·CI·린터·.gitignore 즉시 생성(모델이 매번 새로 안 짬) |
| ② 규칙책 주입 (context-injection) | 판단 필요·프로젝트마다 다름 | 앱 구조 → aspect-02 표준 주입받아 모델이 설계 |
| ③ 실행 게이트 (증거 요구) | 기계로 검증 가능 | 테스트 통과 + 비밀키 0 + CI 초록불 아니면 통과 X |
| ④ 적대적 리뷰 에이전트 | 독립 검증 필요 | 별도 "보안 리뷰어"가 로그인 코드를 깨보려 시도 |
| ⑤ 하드스톱/전문가모드 | 비개발자가 못 가리는 고위험 | "신용카드 저장" → 멈춤: "결제는 위험구역, 전문가 모드" |

→ *지루하지만 확실한 건 템플릿, 판단은 LLM이 규칙책에 이끌려 하고 게이트가 검증.* (LLM 특성을 살리되 바는 체크로 강제.)

**흐름 예 (운동앱):**
- **①기획** — skill 인터뷰(aspect-01 주입): "로그인=개인정보죠? 누가 접근? 보관 기간?" → `prd.yml`. "결제 추가"하면 hook **하드스톱**.
- **②포석** — 필수파일=**템플릿** 즉시 생성 · 앱 구조=**규칙책 주입** · "걷는 뼈대"가 **CI 초록불 될 때까지 ② 안 끝냄(게이트)**.
- **③구현** — **TDD**(실패 테스트 먼저, aspect-08) → 모델 코드 → 코드/보안 **리뷰어 sub-agent가 깨보기** → **게이트**(테스트·비밀키·CI). 핵심: "테스트 *파일이 있다*"가 아니라 "테스트가 *진짜 검증하나*" = **존재가 아니라 증거**(ADR-0014).
- **④릴리스** — 버전·체인지로그·배포=**템플릿** · 공개 직전 **하드스톱 확인** · 롤백 실제 동작 **게이트**.

**범용성:** 같은 5방식 + 같은 코퍼스, 프로젝트 종류마다 *켜지는 aspect만 다름*(CLI→a11y off, data-ml→MLOps on, 결제→하드스톱). **새 타입 = 새 엔진이 아니라 aspect 켜기.**

**dogfood:** 사용자에게 해줄 이 과정을 **gingoa 자신에게 먼저 적용** → gingoa 레포가 "잘 만들었다"의 첫 증거물.
