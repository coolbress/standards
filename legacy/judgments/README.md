## 인용 규칙

1. 이 층은 **판단이거나 역사**다. 사실이 필요하면 [`corpus/`](../../corpus/)로 간다.
2. `SUPERSEDED` 배너가 붙은 문서는 **활성 근거로 인용하지 않는다.** 인용해야 하면
   `corpus/`에 승계된 사본을 찾고, 없으면 [`audit/GAPS.ko.md`](../../audit/GAPS.ko.md) **R5-1**에 등재한다.
3. 인용할 때는 **status를 병기한다** (README 절대규칙 3).

## 왜 안 지웠나

`goppi/foundation/workflow-standard.md`는 cross-vendor 적대 리뷰를 거쳐 **rev4**까지 간 설계다.
하네스는 죽었지만 **인수기준 안정 ID · `AC-n → 검사` 매핑 · `UNVERIFIABLE` 표기**(WF-01)는 살아 있고
`direction/03`이 근거로 인용한다. 두 헌법(gingoa 65줄 · goppi 64줄)은 나란히 두면
*"무엇을 상시 주입할까"* 의 두 답을 보여준다 — **둘 다 50줄 남짓이었고 둘 다 실패했다.**
