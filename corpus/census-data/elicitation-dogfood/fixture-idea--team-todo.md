# Idea — shared team to-do (the builder's words)

> A small team wants a shared to-do list they each run on their own machines: add a task, give it an
> owner, mark it done, and see what's still open. No sign-in and no payments — the list lives as a file
> in a folder the team already shares (a synced drive). It's a local command-line tool.

This is the natural-language input. `prd.yml` in this directory is the **expected** elicited output —
the document a converged interview should produce. The eval grader runs that `prd.yml` through the
Slice-1 lock-gate (it must lock cleanly).
