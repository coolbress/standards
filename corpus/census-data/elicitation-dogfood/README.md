## 왜 이것이 값어치가 있나

트랜스크립트 자신이 무엇을 기록하는지 밝힌다 — *"per-PR 게이트가 **일부러 시험하지 않는** 모델 전용 층:
질문의 **어법**(Mom Test · 턴당 ≤2)과 답변 → 구조화 조각 **추출**."*

즉 **자동 검사로는 잡히지 않는 부분**의 유일한 증거다. 첫 질문이 그 처방의 실물이다:

> *"저장해둔 링크를 실제로 찾으러 갔던 **마지막 때**를 말해주세요 — 무엇을 찾으려 했고, 어디에 저장해뒀었나요?"*

**과거의 구체적 사건**을 묻고, 아이디어에 대한 의견을 묻지 않는다. `direction/04`의 `/kickoff` 설계가
*"Mom Test 스타일 — 유도·가정 질문 금지, 과거의 구체적 행동에 근거"* 라고 적은 것의 **작동 예시**다.
