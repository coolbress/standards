# Idea — batch file renamer (the builder's words)

> A command-line tool that renames a bunch of files in a folder by a pattern (like "photo-001.jpg,
> photo-002.jpg…"). I want to see exactly what it will do before it does anything, then say go. And if I
> mess up, let me undo the last batch. It only touches files on my own machine.

This is the natural-language input. `prd.yml` in this directory is the **expected** elicited output.
The eval grader runs that `prd.yml` through the Slice-1 lock-gate (it must lock cleanly).
