# direction — 앞으로 어디로 가는가

이 저장소의 **결론 층**이다. 나머지 세 층이 *무엇이 사실인가*(`corpus/`) · *과거에 무엇을 지었고 그때 무엇을 판단했나*(`legacy/`) · *무엇을 검증했나*(`audit/`)를 담는다면,
여기는 **그래서 이제 무엇을 할 것인가**를 담는다.

## 이 층의 규칙

1. **주장에는 근거를 건다.** `corpus/` 또는 `legacy/LINEAGE.md`의 실측을 링크한다.
   근거 없는 판단은 *"프로젝트 판단"* 으로 명시한다 — 근거를 가장하지 않는다.
2. **`legacy/judgments/goppi/foundation/`과 혼동하지 않는다.** 그쪽은 **폐기된 하네스(goppi)의 판단**이고,
   여기는 **그 실패 이후의 방향**이다. 둘이 충돌하면 여기가 현행이다.
3. **바뀌면 판수를 올리고 사유를 남긴다.**
