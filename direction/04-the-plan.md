## 만들 것 — 아홉 개

| # | 만들 것 | 어느 요구를 채우나 | 성격 |
|---|---|---|---|
| 1 | **브랜치 보호 · 룰셋** (`bypass_actors: []`) | ① | 🔒 벽 |
| 2 | **`coolbress/workflows`** — 재사용 워크플로(ci · pipeline-guard) | ①② | 🔒 벽 |
| 3 | **`coolbress/project-template`** — Issue Form · PR 템플릿 · `CLAUDE.md`(20줄) · 5줄 `ci.yml` | ①② | 1회 복사 |
| 4 | **`~/.claude/commands/kickoff.md`** — 기획 인터뷰 | ②③ | 🤝 안내 |
| 5 | **`ruleset.json` + `new-project.sh`**(4줄) | 반복 제거 | 1회 실행 |
| 6 | **`@claude` PR 리뷰어** — diff만 보는 제3자 | ① | 🤝 안내 |
| 7 | **세션 시작 이슈 낭독 훅** | ④ | 🤝 기억 |
| 8 | **`~/.claude/CLAUDE.md` 전역 규칙** — ⓐ 쉬운 말이 **기본값** ⓑ **결정 회부 기준**(무엇을 묻고 무엇을 재량으로) ⓒ 선택지엔 근거·위험·불확실성을 함께 | **③** | 🤝 안내 |
| 9 | (나중) 라우팅 표 6줄 + `consensus` MCP + `clink` | **⑤** | 속도 |

**요구 ⑥(전략 전환 기준)은 아직 만들 것이 없다.** CI 연속 실패·같은 파일 반복 수정 같은
**막다른 길 신호**를 무엇으로 잡을지 미설계다 — 리서치의 *circuit-breaker · 진동 감지*
([`03`](03-what-research-says.md) 라우팅 절)가 출발점이고, `audit/GAPS`에 열어둔다.

## 리서치에서 나온 구체 수치 — 이대로 박는다

[03](03-what-research-says.md)에서 도출. **상식으로 정하지 않는다.**

| 항목 | 값 | 왜 |
|---|---|---|
| PR diff 상한 | **400줄** | 400 초과에서 결함 발견율 급락 (Google 중앙값 24줄) |
| CI 소요 | **10분 이내** | 진짜 CI의 조건 |
| main 빨간불 | **다른 일보다 우선 수리** | *"깨지면 즉시 수리"* |
| 리뷰 응답 | **자동 — 사람 대기 0** | 리뷰 속도가 배포 성과의 50% 요인 → `@claude`가 여기서 유리하다 |
| 이슈 필수 | **크기 조건부** — 사소한 변경은 바로 PR | 보편 규칙이 아니다 (census) |
| Conventional Commits | **PR 제목만**, release-please가 소비할 때만 | 이슈 제목 CC는 야생에서 ≈1% |
| PR 체크리스트 | **최소화** | 형식 체크리스트는 DORA 안티패턴 |
| 첫 조각 | **walking skeleton** — end-to-end 한 줄기 | 루프가 단위 |
| 가드 깊이 | **위험 비례** — 모든 PR에 같은 가드를 걸지 않는다 | 깊이는 위험에 비례 |

## `/kickoff`가 지켜야 할 것

[03](03-what-research-says.md) 기획 절에서 도출:

- Mom Test 스타일 — **유도·가정 질문 금지**, 과거의 구체적 행동에 근거
- **턴당 ≤2문항**, 위험별 8/12/18턴
- 인수기준에 **안정 ID**(`AC-1`…) + `AC-n → 검사` 매핑
- 매핑 불가하면 **`UNVERIFIABLE`로 표시하고 알린다** — 조용히 통과 금지
- **"안 만들 것"**(범위 밖)을 명시적으로 받는다
- **흔한 인터뷰 실수 목록**을 함께 넣는다 (실증: 그래야 사람을 이긴다)

## 이 계획이 부수적으로 해소하는 것

**P4(오버헤드) · P10(하네스가 과하면 독)은 짓지 않기로 한 결정 자체가 해법이다.**
로컬에서 매 턴 도는 것이 0이 됐다 — 벽이 서버에 있기 때문이다. 하네스가 없으면 하네스 비용도 없다.

**P19·P20(내부 규율)** 은 하네스를 만들던 우리의 것이었다 — **하네스가 없으므로 소멸한다.**

**P21b(last-mile)** 는 두 곳에서 잡힌다 — `/kickoff`가 S0에서 사람이 해야 하는 단계를 미리 묻고,
배포는 **Environments 보호 규칙**이 강제로 사람을 세운다.

## 명시적으로 원하지 않는 것

| ✕ | 왜 |
|---|---|
| 다섯 번째 하네스 | 다섯은 이미 팔고 있고 더 강하다 |
| 세팅 자체에 시간 쓰기 | 도구를 짓든 세팅하든 같은 모양의 시간이다. **상한: 반나절** |
| 긴 프롬프트로 워크플로 가르치기 | 협조 위의 자물쇠. Fable 5는 과도한 규정에서 품질이 떨어진다 |
| 벽보다 도구를 먼저 늘리기 | 순서를 뒤집으면 아무도 안 막는 코드를 더 빨리 만든다 |
| 모든 PR에 이슈 강요 | census: 크기 조건부. 오타에 이슈를 요구하면 **내가 규칙을 우회하기 시작한다** |
