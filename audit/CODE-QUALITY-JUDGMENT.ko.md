## 2. 🔴 2026 실증이 설계를 정한다 — **에이전트의 자기개선이 품질을 악화시킨다**

**1차 확인** — arXiv [`2603.13723`](https://arxiv.org/abs/2603.13723)(MSR 2026 Mining Challenge).
AIDev 데이터셋에서 **가독성 관련 키워드를 가진 커밋 403건**을 분석:

| | |
|---|---|
| **Maintainability Index 가 하락한 커밋** | **56.1%** |
| **Cyclomatic Complexity 가 증가한 커밋** | **42.7%** |
| 에이전트가 손댄 것 | logic complexity **42.4%** · documentation **24.2%** (이름·포맷 같은 표면은 거의 안 건드린다) |
| 저자 결론(원문) | *"AI agent-based refactoring **specifically improves code readability remains unclear**"* |

⚠️ **한정을 지우지 않는다**: **키워드로 고른 표본**이라 무작위가 아니고, MI·CC 는 **가독성의 대리지표**다.
저자 스스로 *"unclear"* 라 쓴다 — *"AI 리팩터링은 나쁘다"* 로 읽으면 범주 오류다.

🔵 **그런데 방향은 우리 원칙 02 를 정확히 확증한다** —
***"완료는 주장이 아니라 머지된 커밋이다. 에이전트의 자기평가를 기계 판정으로 대체한다."***

👉 **그러므로 *에이전트에게 좋은 코드를 쓰라고 가르치는 층* 은 실측이 가장 약하다고 말하는 층이다.**
힘은 **기계 판정(ⓐ)과 제3자 리뷰(ⓒ)** 에 실어야 한다.
