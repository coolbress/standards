## `/kickoff` vs `grilling` — 상세

### 🟢 `grilling` 이 **우리보다 나은 것** 둘

**① `frontier` 가 우리의 열린 공백을 메운다.**
우리는 *"위험별 깊이 8/12/18턴"* 을 쓰는데 **출처가 없어 🔵(판단)로 내려간 항목**이고,
[`evidence-holes-register`](../corpus/methods/evidence-holes-register.md) **EVH-004** 에
*"인터뷰 깊이의 정지 기준을 찾지 못했다"* 로 등재돼 있다.

> `grilling` 의 정지 기준: ***"frontier 가 비면 끝"*** — 모든 가지를 방문했고 조용히 가정된 게 없으면 끝난다.
> **턴 수를 정할 필요가 없다. 정지 기준이 구조에서 나온다.**

**② 각 질문에 추천 답을 붙인다.**
우리 *"턴당 ≤2문항"* 은 부담을 **양**으로 줄이는데, 이건 **난이도**로 줄인다.
문제 지도 **P13**·**P14**(*선택지·근거·위험이 안 드러남*)를 직접 친다.

### 🔴 `/kickoff` 에 있고 `grilling` 에 **없는** 것 넷

| | 왜 버릴 수 없나 |
|---|---|
| **Mom Test + 흔한 실수 목록** | `ELI-001`(**통제실험 2개**)이 *"실수 목록을 쥐고 있을 때만 사람을 이긴다"* 를 보였다. **우리 근거 중 가장 강한 것이 가리키는 층이 통째로 없다** |
| **산출물 계약** | AC 안정 ID → **검사 매핑** → 불가 시 `UNVERIFIABLE`. `grilling` 은 *"shared understanding"* 에서 끝나고 **실행하지 말라고까지** 한다 |
| **0번 절 — 이미 있는지 확인** | 이 프로젝트에서 **10번 재발한 실수**를 막는 장치. **세 번 발화해 세 번 막았다** |
| **아키타입 hard-stop** | 공개 노출 · 개인정보 · 라이선스 — **법적 의무를 부르고 되돌릴 수 없는 것** |

→ **처분: 대체하지 않고 흡수한다.** `grilling` 의 **frontier 정지 기준**과 **추천 답 동봉**을 `/kickoff` 에 넣고,
위 넷은 유지한다. `to-spec`·`to-tickets` 는 **이슈 트래커 설정을 전제**하므로 우리 룰셋과 충돌 여부를 먼저 본다.
